Um outro aspecto relevante para as classes são os métodos que especificam serviços prestados pelas peças de software daquele tipo ao programa.  \
Quando especificam serviços completos devem ser públicos mas quando representam apenas parte de um serviço não podem ser públicos já que a execução incompleta de um serviço seria uma antise e poderia colocar as peças de software em um estado de inconsistência.  \
Métodos podem ser procedimentos ou funções lembrando que procedimentos não retornam nada, são void, enquanto funções retornam, não são void.  \
Construtores são um estranho tipo de método que tem as seguintes características esquisitas: 
### A. Não podem ter seus nomes livrementes escolhidos; Seus nomes precisam ser o mesmo nome da classe
### B. Não retornam nada e portanto deveriam ser void mas da erro de compilação escrever que são void; Não se escreve nada sobre o que retorna.
### C. Não são explicitamente chamados; Executam automáticamente quando uma peça de software daquela classe for criada.
<hr>
A criação de uma peça de software de uma classe chamada C seria feita assim: new C () quando a classe não tiver construtor ou quando tiver um construtor padrão que é um construtor sem parâmetros. <br>Se há parâmetros a criação de uma peça de software seria feita assim: New C (parâmetros de construtor)<br>O papel do constutor é inicializar os atributos e esse papel jamais deveria ser cumprido por um setter. Setters são para atualizar.
